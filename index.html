What a proof proves

Verifiable execution.Precisely defined.

Customers check cryptographic evidence instead of trusting the operator. Here is exactly what that evidence covers. Try TAMPER RESULT and BAD INPUT on the machine above to see both.

✓ PROVES

The program ran correctly

The output really came from running the specified program on the given inputs. A faked or altered result fails verification.

✓ PROVES

Without redoing the work

The verifier checks a small proof instead of repeating the whole computation.

✗ DOESN'T PROVE

That the inputs were accurate

Garbage in still gives a valid proof of garbage out. Input quality is a separate check.

✗ NOT AUTOMATIC

Privacy, or Solana verification

Privacy depends on how the program is built, and on-chain checks need compatible verifier infrastructure on Solana.
